# Wedding QR — نظام دعوات الزفاف

## المزايا
- لوحة أدمن لإدارة تفاصيل الحفل والثيم.
- إنشاء دفعة من 1 إلى 500 دعوة مرقّمة تلقائياً، ولكل دعوة QR ورابط وكلمة مرور مستقلة.
- دعوات فردية يدوية اختيارية.
- عرض حالة كل دعوة، نسخ الرابط، عرض كلمة المرور، تحميل QR منفرد، إعادة التفعيل أو الحذف.
- صفحة طباعة جميع الدعوات؛ من نافذة الطباعة اختر Save as PDF لحفظها في ملف PDF متعدد الصفحات.
- تحميل ZIP يحتوي على QR PNG، وتصميم الدعوة بصيغة SVG، وملف بيانات الدخول والرابط لكل دعوة.
- تصدير CSV يحتوي على الروابط وكلمات المرور وحالة الدخول.
- سكانر QR للأدمن، ويقبل الرمز مرة واحدة فقط.
- قاعدة SQLite.

## تشغيل على Windows 11
1. فك ضغط الملف.
2. افتح المجلد `wedding_qr_final` في VS Code.
3. افتح Terminal داخل VS Code واكتب:

```powershell
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

4. افتح `http://127.0.0.1:5000/admin/login`.

## ملاحظات مهمة قبل النشر
- غيّر `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`SECRET_KEY` في متغيرات البيئة قبل نشره.
- فعّل HTTPS واضبط `COOKIE_SECURE=1` عند استخدام HTTPS.
- استخدم تخزيناً دائماً لملف SQLite أو قاعدة بيانات مُدارة؛ لا تعتمد على قرص مؤقت في الاستضافة.
- لا ترسل ملف CSV أو ZIP الذي يحتوي كلمات المرور إلا للأشخاص المخولين.
- الطباعة إلى PDF تتم من المتصفح: زر PDF/طباعة الكل ثم اختر Save as PDF.
- ملفات الدعوات في ZIP بصيغة SVG قابلة للفتح كصور متجهية؛ QR منفصل بصيغة PNG.

## نشر Render
ملف `render.yaml` مرفق كإعداد ابتدائي. راجع إعدادات الاستضافة والتخزين الدائم وخطة الخدمة الحالية قبل النشر. لم يتم نشر التطبيق تلقائياً.
