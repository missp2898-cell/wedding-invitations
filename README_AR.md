# Wedding QR — النسخة النهائية للمشروع

## المزايا
- دخول أدمن باسم `ayoub` وكلمة مرور افتراضية `ayoubayoub` للتجربة المحلية.
- تعديل أسماء أصحاب الحفل والعروسين والتاريخ والقاعة ووقت الاستقبال والزفة ونص الدعوة والألوان.
- إضافة كل مدعو باسمه وكلمة مرور تختارها.
- رابط منفصل لكل مدعو؛ يلزمه إدخال الاسم وكلمة المرور لفتح الدعوة.
- QR خاص بكل مدعو، ولا يمكن استعماله إلا مرة واحدة.
- سكانر كاميرا الهاتف، مع رفض الباركود المستعمل سابقاً.
- إعادة تفعيل الدعوة مع إنشاء QR جديد، حذف دعوة، بحث، وتصدير قائمة CSV.
- قاعدة بيانات SQLite.

## التشغيل على Windows 11
افتح مجلد المشروع في VS Code، ثم Terminal ونفّذ بالترتيب:

```powershell
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:5000`.

بيانات الدخول المحلية:
- Username: `ayoub`
- Password: `ayoubayoub`

## النشر
يوجد ملف `render.yaml` لإعداد Render مع قرص دائم. ارفع المشروع إلى مستودع GitHub، ثم أنشئ Web Service منه. أدخل كلمة مرور أدمن جديدة وقوية في متغير `ADMIN_PASSWORD`. اترك `SECRET_KEY` الذي يولده Render كما هو. تأكد من وجود القرص الدائم على `/var/data` ومن أن `DATABASE_PATH` يشير إلى `/var/data/wedding_qr.sqlite3`.

يجب نشر الموقع على HTTPS حتى تعمل كاميرا الهاتف. تحقق من أسعار وخطط الاستضافة الحالية قبل النشر.

## أمان
غيّر كلمة مرور الأدمن الافتراضية قبل أي استخدام حقيقي. لا ترسل بيانات الأدمن للمدعوين. أرسل لكل مدعو رابط الدعوة واسمه وكلمة المرور الخاصة به. خذ نسخة احتياطية من قاعدة البيانات. هذه نسخة مشروع مكتملة للتشغيل والتجربة، ويجب اختبارها على الاستضافة الفعلية قبل الاعتماد عليها في حفل حقيقي.
